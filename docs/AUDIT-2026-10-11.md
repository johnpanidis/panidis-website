# Audit dev.panidis.eu — 2026-10-11

**Μέθοδος:** μόνο GET requests (REST API με Application Password + δημόσια GET), με παύση ~1s ανάμεσα στα requests. Καμία αλλαγή στο site. Το frontend του dev είναι πίσω από το plugin «Under Construction», οπότε ό,τι απαιτεί προβολή της σελίδας ως επισκέπτης (header/footer, 404, sitemap, κουμπιά κοινοποίησης, meta tags του Rank Math) **δεν ήταν ελέγξιμο** και μπήκε στους χειροκίνητους ελέγχους.

**Κλίμακα:** 🔴 Κρίσιμο (εμποδίζει το launch) · 🟠 Υψηλό · 🟡 Μεσαίο · ⚪ Χαμηλό

## Σύνοψη

- Το site είναι τεχνικά υγιές: WordPress 7.1.3, PHP 8.2.34, MariaDB 10.11, Site Health «καλό» σε 5/6 ελέγχους, όλα τα 14 εξωτερικά links και όλα τα εσωτερικά links λειτουργούν.
- **Περιεχόμενο:** 19 πλήρεις σελίδες, 3 ελλιπείς, 1 κενή (Λήψεις). Καμία σελίδα δεν έχει εικόνες — όλο το media library είναι 2 αρχεία λογοτύπου.
- **Μεγαλύτερα κενά πριν το launch:** δεν υπάρχει Πολιτική Απορρήτου / Όροι Χρήσης ενώ οι φόρμες συλλέγουν προσωπικά δεδομένα· η φόρμα Καριέρας ζητά βιογραφικό χωρίς πεδίο επισύναψης· η αγγλική γλώσσα είναι ενεργή χωρίς καμία σελίδα· δεν υπάρχει σχέδιο 301 για τα URLs και τα 23 άρθρα του live.
- **Τεχνικό χρέος:** 21 από τις 23 σελίδες είναι ένα ενιαίο block «Custom HTML» (~13 KB το καθένα) με σκληροκωδικοποιημένα links `https://dev.panidis.eu/...` — δύσκολη επεξεργασία και ανάγκη search-replace στη μεταφορά.
